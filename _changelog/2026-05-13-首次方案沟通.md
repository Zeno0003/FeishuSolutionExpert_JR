# 2026-05-13 首次方案沟通纪要

## 用户现状

- 刚毕业，软件工程 + 辅修投资学，唯一技术人员
- 20+ 人自有货盘电商，多平台销售，全链条团队
- 手上有收货清点记录等多张 Excel 表，但数据各自独立

## 本次产出

1. **MVP 整体方案**：设计了 5 张表的核心架构（供应商、商品信息、采购入库、销售出库、库存计算）
2. **项目目录结构**：搭建了 `_plans / _business / _data / _decisions / _changelog` 的分层结构
3. **关键决策**：
   - 只使用飞书原生功能，不涉及 API
   - 库存计算嵌入商品信息表而非独立建表
   - 从"收货清点记录"作为起点，往前追溯采购、往后驱动库存
