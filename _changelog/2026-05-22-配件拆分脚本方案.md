# 2026-05-22 配件拆分脚本方案

## 问题
用户在辅助表格输入整机收货记录，拖拽填充「自动生成」字段时，飞书自动化并发执行，导致收货表中配件记录（L/R/C）生成顺序错乱。

## 根因
飞书原生自动化「修改字段」触发是异步并发的。N 条记录同时修改 = N 个自动化实例同时运行，彼此交叉插入写入。

## 方案
- 改用「按钮 + 脚本」模式：操作面板中一个按钮触发 JavaScript 脚本
- 脚本用 `for...of` + `await` 保证串行：逐条整机 → 逐条配件（L→R→C），不交叉
- 复选框「自动生成」降级为纯标记字段，不再触发自动化
