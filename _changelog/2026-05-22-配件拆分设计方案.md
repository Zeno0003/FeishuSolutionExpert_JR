# 2026-05-22 配件拆分设计方案

## 问题
辅助表格输入整机收货记录，需在收货表生成 L/R/C 三条配件记录。拖拽填充触发字段导致飞书自动化并发执行，配件记录交叉写入，顺序错乱。

## 产出（三个方案，层层递进）

1. **无脚本按钮方案** (`_plans/06-补充-无脚本按钮方案.md`)
   - 复选框→按钮字段，逐行点击天然串行
   - 配件序号+排序视图保证显示顺序
   - 适合日处理量 < 30 条

2. **自动化脚本方案** (`_plans/06-配件拆分脚本方案.md`)
   - 操作面板按钮 → 运行 JavaScript 脚本
   - `for`+`await` 串行处理，单次最多 200 条

3. **自研插件方案** (`_plans/07-自研插件方案.md`)
   - React + TypeScript 多维表格扩展
   - Phase 1 配件拆分已搭建（`plugin/` 目录）
   - Phase 2 批量导入 Excel 骨架已建
   - 未来可扩展定时任务、审批流等

## 项目文件
- `plugin/` — Bitable 扩展插件项目（Phase 1 可运行）
