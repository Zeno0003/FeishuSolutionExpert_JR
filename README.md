# 飞书电商数字化 MVP 项目

> 20+ 人自有货盘电商公司，多平台销售（淘宝/拼多多/抖音），全链条团队。
> 目标：用飞书多维表格（Bitable）零代码替代分散的 Excel，实现进销存数据实时联动。

## 目录导航

| 目录 | 用途 | 谁维护 |
|------|------|--------|
| `_business/` | 公司业务现状、流程描述、Excel 清单 | 你提供素材，AI 整理 |
| `_plans/` | 飞书多维表格设计方案（MVP 及后续） | AI 产出 |
| `_data/` | 原始 Excel 文件、截图、飞书导出备份 | 你丢进来 |
| `_decisions/` | 关键决策记录（选 A 不选 B 的原因） | 共同维护 |
| `_worklog/` | 你的个人工作日志（手动维护） | 你 |
| `_changelog/` | 每次交流的纪要，按日期归档 | AI 产出 |

## 使用方式

1. 把公司现有的 Excel 表文件放进 `_data/excel/`
2. 告诉我 "我更新了 _business 里的 xx"，我会读取并基于最新信息调整方案
3. 每次只聊一个模块（比如今天只聊采购入库），聊透再换下一个
