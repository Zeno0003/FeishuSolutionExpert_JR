# 业务架构与数据流转 SOP

> 最后更新：2026-05-25 | 维护：AI + 人工审核 | 用途：公司级业务架构总览

---

## 一、业务概览

**公司形态**：20+ 人自有货盘电商，多平台销售（淘宝/拼多多/抖音），全链条团队。

**主营品类**：二手 TWS 耳机（华为 FreeBuds 系列为主），按组件（充电仓/左耳/右耳）独立采购和质检。

**核心业务闭环**：

```
采购下单 → 到货签收 → 质检分级 → 清洁修复 → 入库上架 → 多平台销售 → 拣货出库
```

**外部系统**：公司另有 ERP 系统管理货物，以及采购网站在线下单。采购网站可导出"今日采购表明细表"Excel（详见 `_business/今日采购表明细表.md`）。

**数据入口**：采购数据从外部系统进入飞书的完整路径：

```
采购网站 Excel → 复制三列（物品编号/商品名称/合计）
    → 辅助填表_采购收货(芳)（整机粒度，一行 = 一套耳机）
    → 飞书自动化 1→3 拆分（自动生成 C/L/R 三条组件记录）
    → 采购收货表（组件粒度，一行 = 一个组件）
```

**飞书多维表格定位**：零代码替代分散的 Excel，实现进销存数据实时联动。当前 MVP 阶段优先跑通采购→入库链路，销售出库待启动。

**飞书自动化机制**（1 条 → 3 条拆分配件）：

| 序号 | 步骤 | 内容 |
|------|------|------|
| 触发条件 | 新增记录时 | 发货日期≠空 AND 物流单号≠空 AND 供应商名称≠空 AND 颜色≠空 AND 成色≠空 AND 商品型号≠空 |
| 第 2 步 | 新增记录到采购收货表 | 映射全部字段，配件 = **L**（左耳） |
| 第 3 步 | 新增记录到采购收货表 | 映射全部字段，配件 = **R**（右耳） |
| 第 4 步 | 新增记录到采购收货表 | 映射全部字段，配件 = **C**（充电仓） |

> **未来替代方案**：`server/` 自研 SDK 工具（`_plans/07-自研插件方案.md`）可替代此飞书自动化，实现更灵活的拆分逻辑。当前自动化方案稳定运行中，暂不切换。

## 三、核心业务 SOP

### SOP-1：采购网站数据导入与拆分配件（每日 1~N 次）

```
1. 采购网站导出「今日采购表明细表」Excel
2. 只复制三列：物品编号 / 商品名称 / 合计
3. 飞书 → 辅助填表_采购收货(芳) → 新建行
4. 粘贴物品编号到「文本」字段（物品编号作为唯一标识溯源）
5. 逐行补充：发货日期、物流单号、供应商名称、颜色、成色、商品型号
6. 将「点击自动生成」选为"自动生成"
7. 飞书自动化触发（需满足触发条件），自动在采购收货表生成 3 条：
   - 配件 = L（左耳）
   - 配件 = R（右耳）
   - 配件 = C（充电仓）
   → 每条自动继承：发货日期、物流单号、供应商、型号、颜色、成色
8. 自动化执行完毕 → 勾选「已拆分」
⏱ 耗时：30 秒/行（填一行 = 生成三行）
```

### SOP-2：到货登记

```
1. 快递到仓 → 仓管打开飞书 → 采购收货表 → 📦 到货登记 视图
2. 扫码枪扫商品条码 → 自动匹配商品编码
3. 输入：物流单号、发货数量、到货数量、采购短号
4. 系统自动生成 DH 编号、判断到货差异
⏱ 耗时：30 秒/行
```

### SOP-3：平台采购件关联（货物到仓后）

```
1. 飞书 → 平台采购记录表 → 📥 待拆分 视图
2. 打开一条记录，确认实物已到
3. 打开采购收货表，找到已通过辅助填表(芳)自动生成的 3 条 C/L/R 记录
4. 将每条记录的「来源平台单」关联回平台采购记录表
5. 回到平台采购记录表，关联这 3 条，标记「已拆分」
⏱ 耗时：30 秒/条
```

> 注：C/L/R 三行的自动拆分已在 SOP-1 通过辅助填表(芳) + 飞书自动化完成，此处只需补充平台溯源关联。

### SOP-4：质检操作

```
1. 质检员打开手机飞书 → 采购收货表 → 📋 质检工作单 视图
2. 找到对应物流单号分组，展开看到所有待检 SKU
3. 逐行检测，填入：
   - 退货坏品数（Mode 1：退回供应商）
   - 补差坏品数（Mode 2：补差留货）
   - 坏品处理方式（退回供应商 / 留入主仓-待清洁）
4. 系统自动计算：测试坏品数、实付金额、可入库数量
5. 全组 SKU 检测完毕 → 填「测试完成日期」
6. 该分组自动从视图消失
⏱ 耗时：按实物数量
```

### SOP-5：清洁处理

```
1. 清洁员打开采购收货表 → 🧹 待清洁 视图
2. 显示所有需要清洁的行（良品 + 坏品留仓）
3. 清洁完成后：
   - 确认/修正「成色划分」（08/09/10）
   - 填写各成色数量
4. 走「生成主仓入库单」→ 入主仓
```

### SOP-6：采退结算

```
1. 财务打开采购收货表 → 💰 结算总览 视图
2. 按物流单号分组，每组显示：
   - 采购总额 / 退货冲减 / 补差冲减 / 实付合计
3. 确认支付人 → 打款 → 标记已支付
4. 导出按物流单号汇总对账
```

### SOP-7：兼职工作日志录入

```
1. 管理员打开兼职工作日志 → 新建记录
2. 关联采购收货记录（自动带出物流单号/采购短号/商品编码）
3. 选工作人员、工作类型、完成数量
4. 手动填工资单价（按物品难易度灵活定价）
5. 选支付周期（按天/按周）→ 填周期标记
6. 小计工资自动计算
7. 结算日 → 按周期标记分组 → 汇总 → 支付 → 标记已支付
```
