# 07 — 自研多维表格工具集（服务端方案）

> 产出日期：2026-05-22 | 更新：2026-05-23 | 状态：Phase 1 代码已完成，配置 .env 后即可使用

## 背景

前任方案（Bitable Extension 插件，React + `@lark-base-open/js-sdk`）受限于多维表格插件沙箱，无法实现 Phase 3（定时任务 + 群通知）和 Phase 4（审批流打通）。

2026-05-23 决策：**放弃插件路线，改用服务端 SDK 路线**（Direction B），使用 `@larksuiteoapi/node-sdk` 直接调用飞书 REST API。一套代码覆盖全部 Phase 1~4。

旧插件代码保留在 `plugin/` 目录，不再维护。

## 技术栈

| 层 | 技术 |
|----|------|
| 语言 | TypeScript 5.x |
| 运行时 | Node.js 22+ |
| 飞书 SDK | `@larksuiteoapi/node-sdk`（服务端 SDK，通过 REST API 调飞书） |
| Web 框架 | Express 4.x |

## 项目位置

`server/` — 独立子项目，位于仓库根目录下。

## Phase 1：配件拆分（已实现）

**入口**：Web 界面 → 「配件拆分」Tab → 点击「一键拆分配件」

**流程**：
1. 通过 REST API 查询来源表中所有 `待拆分=true 且 已拆分≠true` 的记录
2. 按整机编号排序
3. `for` + `await` 串行逐条：写入 L → R → C → 标记已处理
4. 通过 SSE 实时推送进度条和成功/失败计数

**并发控制**：JavaScript 单线程 `for` + `await` 保证绝对串行，不存在交叉。

## Phase 2：批量导入（已实现）

**入口**：Web 界面 → 「批量导入」Tab

**流程**：选择目标表 → 加载字段 → 上传 Excel/CSV → 自动解析预览 → 映射列到飞书字段 → 确认后串行写入

**支持格式**：`.xlsx` / `.xls` / `.csv`

## 如何启动

```bash
cd server
npm install
cp .env.example .env   # 编辑 .env 填入实际值
npm run dev             # 启动后打开 http://localhost:3000
```

## 环境变量（.env）

| 变量 | 说明 | 来源 |
|------|------|------|
| `FEISHU_APP_ID` | 应用 ID | 飞书开放平台 → 企业自建应用 |
| `FEISHU_APP_SECRET` | 应用密钥 | 同上 |
| `BASE_TOKEN` | 多维表格 Base ID | Base 浏览器 URL 中 `base/XXXXX` 那串 |

## CLI 模式

```bash
npm run split              # 命令行执行配件拆分
npm run import <file>      # 命令行导入（待实现）
```
