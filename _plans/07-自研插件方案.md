# 07 — 自研多维表格插件方案（配件拆分 + 批量导入）

> 产出日期：2026-05-22 | 状态：Phase 1 代码已搭建，注册飞书应用后可运行

## 背景

前几个方案（无脚本按钮 `06-补充`、自动化脚本 `06`）解决了并发乱序问题，但都在飞书原生自动化框架内，扩展性有限。用户决定**能力优先**，自研飞书多维表格扩展插件（Bitable Extension），作为后续所有工具化需求的承载平台。

## 技术栈

| 层 | 技术 |
|----|------|
| 框架 | React 18 + TypeScript |
| 飞书 SDK | `@lark-base-open/js-sdk` |
| 构建 | Rsbuild |
| 发布 | 飞书开放平台 → 企业自建应用 |

## 项目位置

`plugin/` — 独立子项目，位于仓库根目录下。

## Phase 1：配件拆分（已实现）

**入口**：插件面板 → 「配件拆分」Tab → 点击「一键拆分配件」

**流程**：
1. 查询辅助表中所有 `待拆分=true 且 已拆分≠true` 的记录
2. 按整机编号排序
3. `for` + `await` 串行逐条：写入 L → R → C → 标记已处理
4. 实时显示进度条和成功/失败计数

**并发控制**：JavaScript 单线程 `for` + `await` 保证绝对串行，不存在交叉。

## Phase 2：批量导入（骨架已建，功能待完善）

**入口**：插件面板 → 「批量导入」Tab

**流程**：上传 Excel/CSV → 解析预览 → 映射列到飞书字段 → 确认后串行写入

**依赖**：需 `npm install xlsx papaparse`

## 如何启动

```bash
cd plugin
npm install
npm run dev        # 本地热更新调试
npm run build      # 构建生产包
```

## 如何发布

1. 到飞书开放平台 (open.feishu.cn) 创建企业自建应用
2. 添加能力「多维表格扩展」
3. 配置权限：`bitable:app`、`bitable:record`、`bitable:field`
4. 上传 dist/ 产物
5. 管理员审批后，团队成员可在多维表格中看到插件

## 配置文件

`plugin/src/config.ts` — 表名、字段名、配件定义均集中于此，改动只需改一处。
