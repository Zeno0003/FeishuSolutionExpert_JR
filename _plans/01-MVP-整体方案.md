# 01 — MVP 整体方案：5 张表打通进销存

> 产出日期：2026-05-13 | 状态：v1 初稿，待根据实际 Excel 数据修订

## 背景

- 20+ 人自有货盘电商，多平台销售（淘宝/拼多多/抖音等）
- 已有多张独立 Excel 表：采购、入库清点、库存、销售记录
- 当前问题：Excel 各自独立，数据不通，库存无法实时计算
- 用户已有"入库前收货清点记录"的 Excel 表

## 业务流程映射

```
供应商 ──→ 采购下单 ──→ 到货清点(Excel起源) ──→ 入库上架 ──→ 库存就绪
                                                                      │
                   ┌──────────────────────────────────────────────────┘
                   ▼
              多平台接单 ──→ 审单 ──→ 拣货 ──→ 打包出库 ──→ 物流发出
```

**关键洞察**：收货清点记录是整个数据链条的第一道关卡——从这里开始建表，往前追溯采购、往后驱动库存。

### 表 5：库存计算（嵌入商品信息表）

不单独建表，在商品信息表中通过"查找引用 + 公式"实现：

- `总入库量`（查找引用 → 采购入库表，对实收数量求和）
- `总出库量`（查找引用 → 销售出库表，对出库数量求和）
- `当前库存`（公式）= `总入库量 - 总出库量`
- `库存状态`（公式）= `IF(当前库存 < 安全库存, "⚠️ 低库存", IF(当前库存 = 0, "❌ 缺货", "✅ 正常"))`

## 提效小妙招

1. **扫码自动填充**：飞书移动端打开表格 → 新建记录 → 点击商品字段 → 扫描条码，自动匹配 SKU
2. **关联引用自动带出**：选了商品 → 供应商/规格/单位自动出现
3. **表单模式**：为入库/出库创建飞书表单视图，手机填比表格编辑快 5 倍
4. **自动编号**：单号格式 `RK-20260513-001`，永不重复
5. **公式算差异**：实收 vs 采购自动算差异，一眼看出少发/多发

## 后续升级路线

1. **自动化机器人**：库存低于安全库存 → 飞书消息推送给采购负责人
2. **审批流**：采购申请 → 主管审批 → 自动生成入库单草稿
3. **每日推送**：上午 9 点自动推送昨日入库/出库汇总 + 库存预警到管理群
4. **扫码盘点**：周期性全量盘点，自动对比系统 vs 实盘差异
5. **利润初算**：商品信息表增加成本价/售价，销售出库关联后自动算毛利
