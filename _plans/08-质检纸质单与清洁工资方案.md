# 08 — 质检纸质单 + 坏品分流 + 兼职清洁工资方案

> 产出日期：2026-05-25 | 状态：待执行 | 关联：方案 03（质检数字化）、方案 05（采退结算）

## 背景

现有方案 03 设计了「质检记录表」替代纸质单，方案 05 拆分了「退货/补差」两种坏品处理。
本次方案在此基础上补充三个能力：

1. **质检纸质单** — 即使有数字化表单，纸质单仍是工厂实操中的必需品（工人不习惯手机填表、无信号场景）。需要一张可打印的纸质模板，字段与飞书对齐
2. **坏品分流** — 方案 05 的采退只覆盖了"退回供应商"，缺少"留入主仓 → 清洁"这条路径
3. **兼职工资结算** — 测试/清洁/打磨/复测的工资按**不同物品不同单价**灵活计算，按天或按周汇总

## ① 质检纸质单

### 设计思路

- 飞书电子表单（方案 03 的质检记录表）= 数字化长期记录
- 纸质单 = 工人现场的随手记录工具，事后由专人统一录入飞书
- 纸质单与飞书字段一一对应，减少录入时的"翻译"成本

### 纸质单模板

见 `_business/质检纸质单模板.xlsx`（同目录下自动生成），A4 竖版打印，包含三大区域：

| 区域 | 内容 | 录入方式 |
|------|------|---------|
| **基础信息区** | 采购短号、物流单号、供应商、商品型号、成色、到货日期 | 管理员打印前预填（或工人抄写） |
| **人员&日期区** | 测试员、清洁员、复测人、打磨员、复测件数、开单日期、完成日期 | 工人手写 |
| **质检明细区** | 充电仓/左耳/右耳 三种组件的良品数和坏品数 | 工人手写勾选 |
| **处理判定区** | 坏品处理方式（退回/留仓清洁）、坏品是否可退、备注 | 质检员判定后勾选 |

## ② 坏品分流：两条路径

### 现状
方案 05 已在 `采购收货表` 上做了 `退货坏品数` / `补差坏品数` 的拆分，覆盖了"退回供应商"和"补差留货作零件"两种模式。

### 本次补充："留入主仓 → 清洁"路径

方案 05 的"补差留货"只是结算层面的概念（供应商退钱、货留着），并没有说明留货之后怎么处理。本方案补充物理流程：

```
质检 → 坏品
         ├── 退回供应商 ──────→ 采退结算（方案 05 已覆盖）
         │                     退货坏品数 → 从「生成采退表」走退货流程
         │
         └── 留入主仓-待清洁 ──→ 清洁处理 → 成色分级(08/09/10) → 入库主仓
                                补差坏品数或不可退坏品 → 清洁后按成色上架
```

### 需要新增的字段

**在 `采购收货表` 上新增**：

| 字段名 | 类型 | 选项 | 说明 |
|--------|------|------|------|
| `坏品处理方式` | 单选 | `退回供应商`, `留入主仓-待清洁` | 质检员判定每行坏品走哪条路径 |

> 这个字段决定了后续流程：
> - 选「退回供应商」→ 走方案 05 的采退流程（退货坏品数 / 补差坏品数）
> - 选「留入主仓-待清洁」→ 清洁员接手 → 清洁完毕后填成色划分 → 走「生成主仓入库单」入库

### 已有字段的联动

`采购收货表` 上已有这些字段配合清洁流程：

| 字段 | 已有？ | 在清洁流程中的作用 |
|------|--------|-------------------|

| 清洁良品单价（field 36） | ✅ 已有 | 计算清洁工资的单价（Text 类型，建议改为 Number） |

## ③ 兼职清洁工资计算

### 定价原则

**单价不按工种锁死，按具体物品灵活指定。** 不同型号/成色的耳机，检测和清洁的难度不同：

| 参考单价 | 典型场景 |
|---------|---------|
| 0.3 元/件 | 复杂型号的全面测试 |
| 0.2 元/件 | 标准清洁 + 除胶打磨 |
| 0.1 元/件 | 简单擦拭、表面去灰 |
| ~~0.5 元/件~~ | 已废弃 |

> 「手坏」= 来料即坏（供应商发来就坏了），不是人为损坏。这类坏品经清洁修复后的计件工资，按修复难度灵活定价。

### 支付周期

| 周期 | 周期标记格式 | 示例 |
|------|-------------|------|
| 按天 | `YYYY-MM-DD` | `2026-05-25` |
| 按周 | `YYYY-Www` | `2026-W22` |

管理员在录入工资时选择按天还是按周，结算时按 `周期标记` 分组汇总即可。

| 2 | `物流单号` | 查找引用 | ← 关联采购收货记录.物流单号 | 自动带出，不用手填 |
| 3 | `采购短号` | 查找引用 | ← 关联采购收货记录.采购短号 | 自动带出 |

### 工资录入流程

```
收货完成质检 → 测试员/清洁员已分配 → 管理员在「兼职工作日志」新建记录
    → 关联采购收货记录（自动带出物流单号/采购短号/商品编码）
    → 选工作人员、工作类型、完成数量
    → 手动填工资单价（按物品难易度灵活定价）
    → 选支付周期（按天/按周）→ 周期标记自动生成或手动填
    → 小计工资自动计算
    → 结算日 → 按周期标记分组 → 查看每人合计 → 支付 → 标记已支付
```

| 👤 按人汇总 | 看板 | 按 `工作人员` 分组，卡片显示总工资 | 看每个兼职的累计工资 |
