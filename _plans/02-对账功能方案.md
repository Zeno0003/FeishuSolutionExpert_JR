# 02 — 对账功能设计方案：三层自动对账体系

> 产出日期：2026-05-14 | 状态：v1 初稿 | 基于 `主表.xlsx` 实际数据结构

## 背景

用户现有 Excel（`主表.xlsx`，21 个工作表）已跑通采购→到货→入库的完整数据链路：

```
CGD(采购单) → DH(到货登记) → QC检测 → RKD(入库单)
```

核心业务表：
- **采购收货表**（CGD 编号）：采购下单，含采购数量、单价、供应商
- **采购表/到货登记**（DH 编号）：到货清点，含发货数量、到货数量、差异判断、关联 CGD/RKD
- **质检出入库登记**（RKD 编号）：入库上架，含数量、关联 DH

**当前痛点**：三张表各有编号和数量字段，但缺少跨表自动比对。人工逐行核对采购量 vs 到货量 vs 入库量，容易漏错且看不到全貌。实际数据中已出现"数量不一致""到货数量大于发货数量""坏品数漏填"等问题。

---

📍 第一阶段：业务流程映射

```
供应商发货 ──→ 快递到仓 ──→ 拆包清点 ──→ QC检测坏品 ──→ 良品入库
    │              │           │            │              │
  [CGD采购单]   [物流单号]   [DH到货单]   [坏品数]      [RKD入库单]
    │              │           │            │              │
    └──────────────┴───────────┴────────────┴──────────────┘
                              │
                         对账节点（自动比对）
                              │
              采购量 vs 到货量 vs 入库量 → 差异标记
```

**业务表单流转**：
1. 采购在「采购收货表」填写 CGD 单（采购数量、单价、供应商）
2. 仓库收到快递 → 在「到货登记表」填写 DH 单（扫物流单号、填实收数量）
3. QC 检测 → 在 DH 单中填坏品数 → 系统自动算可入库量
4. 入库上架 → 在「入库登记表」填 RKD 单（关联到货单）
5. **系统自动对账**：每一层差异实时可见，无需人工逐个比对

以 CGD 采购单为主记录，记录"我买了什么"：

| 字段名 | 类型 | 配置/公式 | 提效点 |
|--------|------|-----------|--------|

| 供应商 | 查找引用 ← 商品信息表.供应商 | 选商品自动出 | |
| 单价 | 查找引用 ← 商品信息表.成本单价 | 自动带出，可手动改 | |
| 采购数量 | 数字 | | |
| 采购金额 | 公式 | `采购数量 * 单价` | **自动算** |
| **关联到货记录** | 关联引用 → 到货登记表 | 双向关联 | 一条采购可对多条到货 |

🚀 第四阶段：未来演进路径

### 表格跑顺后可启用的飞书自动化

1. **对账差异自动推送**
   - 触发器：采购收货表.对账状态 ≠ "✅ 一致"
   - 动作：飞书消息推送给采购负责人 → "CGD00052 到货差异，请核对"

2. **QC 漏检提醒**
   - 触发器：到货登记表.到货日期超过 24 小时，且坏品数为空
   - 动作：飞书消息推送给 QC 负责人 → "DH00067 到货已超 24 小时未检测"

3. **入库完成 → 自动更新库存**
   - 触发器：入库登记表新增记录
   - 动作：自动更新商品信息表中的"当前库存"字段

4. **每日对账汇总推送**
   - 定时：每天上午 9:00
   - 内容：昨日采购/到货/入库汇总 + 当前对账差异清单 → 推送到管理群

5. **审批流：采购申请 → 主管审批 → 自动生成采购单**
   - 大额采购需审批，小额自动建单

### 后续可加的进阶模块

- **销售端对账**：平台订单 → 出库 → 物流签收，全链路追踪
- **售后对账**：退款单 ↔ 快递赔付，算清每笔售后的真实成本
- **利润初算**：销售出库关联成本价 → 自动算毛利 = 售价 - 成本 - 快递费 - 退款
- **扫码全量盘点**：手机扫货架条码 → 自动对比系统库存 vs 实盘 → 盘盈盘亏报告
