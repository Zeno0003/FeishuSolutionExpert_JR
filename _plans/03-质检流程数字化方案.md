# 03 — 质检流程数字化方案：从纸质单到飞书表单

> 产出日期：2026-05-17 | 状态：v1 初稿 | 基于 `质检表格.xlsx` 实际数据结构

## 背景

用户现有纸质质检流程：

```
ERP导出采购单 → 复制商家编码+采购数量 → 粘贴到质检模板 → 填采购短号+货源 → 打印
    → 质检部纸笔填结果 → 有问题？纸质单传回仓管
```

痛点：
- **手动复制**商家编码和采购数量，易出错
- **纸质单流转**慢，仓管看不到实时进度
- QC 结果**无数字记录**，无法事后统计良品率、追溯责任人
- 坏品反馈**滞后**，影响入库和退货时效

## 产品特征

当前质检的 TWS 耳机（rmbuds6vital）按组件拆分质检：充电仓(C)、左耳(L)、右耳(R)，每个组件独立计数良品/坏品。质检单模板含多个角色：测试员、清洁员、复测人、打磨员。

📍 第一阶段：业务流程映射

```
┌─────────────┐     ┌─────────────────┐     ┌──────────────────┐     ┌──────────────┐
│ ERP 导出采购单 │ ──→ │ 飞书「采购收货表」 │ ──→ │ 飞书「质检记录表」 │ ──→ │ 仓库入库上架  │
│  (CSV 一键导入) │     │   (自动生成质检单) │     │  (手机扫码填结果)  │     │ (坏品数自动算) │
└─────────────┘     └─────────────────┘     └──────────────────┘     └──────────────┘
                            │                        │                      │
                    自动带出商品信息          关联引用自动带出          坏品数自动汇总
                    自动生成采购短号          商家编码+采购数量        良品自动=应入库量
```

核心变化：
- **消除手动复制**：ERP 导出 CSV → 一键导入飞书「采购收货表」
- **质检单数字化**：飞书表单替代纸质单，质检员手机扫码填良品/坏品数
- **反馈实时化**：仓管在飞书看板实时看到每单 QC 进度，有问题立即知道

🏗️ 第二阶段：MVP 数据底座（核心配置）

## 方案定位

在现有 6 表基础上增强，不推翻重做。现有「到货登记表」的 QC 只有一个 `坏品数` 字段，本次升维为一张完整的「质检记录表」。

## 1. 多维表格设计 — 调整 2 张、新增 1 张

### 表 A：采购收货表（增强）— 现有表 3 追加字段

| 新增字段 | 类型 | 说明 |
|---------|------|------|
| 采购短号 | 文本 | 仓库内部使用的简短批次号，如 `5-12-vital蓝`，可从 ERP 备注提取或手动填 |
| 货源 | 文本 | 货源渠道，如"华强北A档""工厂直发" |
| 关联质检记录 | 关联引用 → 质检记录表 | 双向关联，一条采购可对多条质检（分批到货） |

> 已有字段不变。采购短号是给人读的别名，CGD 编号是系统主键。

### 表 B：质检记录表（★ 本次核心新建）— 替代纸质质检单

| 字段名 | 类型 | 配置/公式 | 设计意图 |
|--------|------|-----------|----------|
| 质检单号 | 自动编号 | `QC-{YYYYMMDD}-{序号}` | 唯一标识，替代纸质单号 |
| 关联采购单 | 关联引用 → 采购收货表 | 双向关联 | **选采购单后，商家编码+数量自动带出** |
| 商品编码 | 查找引用 ← 关联采购单.商品编码 | 自动出 | 不用手动复制 |
| 采购数量 | 查找引用 ← 关联采购单.采购数量 | 自动出 | 作为质检基准数 |
| 测试员 | 人员 | | QC 主检人 |
| 清洁员 | 人员 | | 清洁工序负责人 |
| 复测人 | 人员 | | 二次抽检确认人 |
| 打磨员 | 人员 | | 打磨工序负责人 |
| 开单日期 | 日期 | 默认当天 | |
| 完成日期 | 日期 | | QC 完成时填写 |
| 采退日期 | 日期 | | 需要退货给供应商时填写 |
| 复测件数 | 数字 | | 抽检/复测样本数 |
| 良品-充电仓 | 数字 | | 按组件拆分的良品数 |
| 良品-左耳 | 数字 | | |
| 良品-右耳 | 数字 | | |
| 坏品-充电仓 | 数字 | | 按组件拆分的坏品数 |
| 坏品-左耳 | 数字 | | |
| 坏品-右耳 | 数字 | | |
| 良品总数 | 公式 | `良品-充电仓 + 良品-左耳 + 良品-右耳` | 自动汇总 |
| 坏品总数 | 公式 | `坏品-充电仓 + 坏品-左耳 + 坏品-右耳` | 自动汇总 |
| 良品率 | 公式 | `ROUND(良品总数/(良品总数+坏品总数)*100,1) & "%"` | 一眼看质量 |
| 质检结论 | 公式 | `IF(坏品总数>0, "⚠️ 有坏品", "✅ 全良")` | 自动判断 |
| 备注 | 多行文本 | | 异常说明（破损类型、原因等） |

### 表 C：到货登记表（微调）— 现有表 4 坏品数改为自动引用

| 调整字段 | 原设计 | 新设计 |
|---------|--------|--------|
| 坏品数 | 手动填一个数字 | **查找引用** ← 关联质检记录.坏品总数，自动汇总 |
| 新增：关联质检记录 | — | 关联引用 → 质检记录表，到货→质检双向关联 |

> 应入库量公式不变（`到货数量 - 坏品数`），但现在坏品数自动从 QC 结果汇总。

## 2. 字段级提效小妙招

| 妙招 | 操作 | 消除的痛点 |
|------|------|-----------|
| 📥 CSV 一键导入 | ERP 导出 CSV → 飞书「导入数据」→ 选采购收货表，自动映射列 | **不再手动复制**商家编码和数量 |
| 🔗 关联引用自动带出 | 质检记录表选「关联采购单」→ 商品编码、采购数量全部自动出现 | 不用手工把 ERP 数据抄到模板 |
| 📱 手机表单填 QC | 为质检记录表创建「表单视图」→ 质检员手机扫码 → 只填 6 个数字 | **纸质单变数字单**，3 秒/条 |
| 🧮 良品率自动算 | 填完 6 个数字 → 良品总数、坏品总数、良品率、结论全自动出 | 不用心算，不用 Excel 拉公式 |
| 🔄 坏品数自动回传 | 质检完成 → 到货登记表坏品数自动更新 → 应入库量自动重算 | 数据不脱节，不用人工传话 |
| 👤 人员字段记责 | 测试员/清洁员/复测人/打磨员分别记录 | 出问题能追溯到具体工序和人 |

> **注意**：当前示例产品是 TWS 耳机（3 组件：充电仓/左耳/右耳）。如果未来质检其他品类（如手环）组件不同，可在质检记录表中按需增减良品/坏品字段，或使用飞书多维表格的"动态字段"特性。

📊 第三阶段：可视化看板预览

### 个体端

- **今日待检清单**：看板视图，筛选「完成日期=空」，按开单日期分组。质检员打开飞书就知道今天要检多少单。
- **我的质检记录**：看板视图，筛选「测试员=我」，按质检结论分组（✅全良 / ⚠️有坏品）。

### 管理端（仪表盘）

| 图表 | 类型 | 数据来源 | 看到什么 |
|------|------|----------|----------|
| 🔴 质检完成率 | 环形图 | 质检记录表，按完成日期有无分组 | 到了多少货，检了多少，还剩多少 |
| 📋 坏品明细清单 | 统计列表 | 筛选「质检结论=⚠️有坏品」 | 哪些批次、哪个组件出了坏品，数量多少 |
| 📈 良品率趋势 | 折线图 | 质检记录表按日期汇总良品率 | 供应商质量波动，一眼看出哪批货质量下滑 |
| 👤 质检员工作量 | 柱状图 | 按测试员分组计数 | 谁检了多少单，工作量是否均衡 |
| ⚠️ 待处理坏品 | 统计列表 | 筛选「坏品总数>0 且采退日期=空」 | 有坏品但还没处理退货的，别拖 |

🚀 第四阶段：未来演进路径

表格跑顺后可启用的飞书自动化：

1. **质检完成自动通知入库**
   - 触发器：质检记录表「完成日期」被填写
   - 动作：飞书消息推给仓管 → "QC00023 质检完成，良品3220件，可入库"

2. **坏品自动触发退货流程**
   - 触发器：质检结论 = "⚠️ 有坏品"
   - 动作：自动在「采退日期」填当天 + 推送消息给采购 → "QC00024 检出坏品15件，请发起退货"

3. **质检超时提醒**
   - 触发器：开单日期超过 24 小时且完成日期仍为空
   - 动作：飞书消息推给质检负责人

4. **供应商质量评分**
   - 基于历史良品率自动给供应商打分，采购下单时可参考

5. **扫码溯源**
   - 每件商品入库时贴飞书生成的二维码 → 售后时可扫出哪批采购、谁质检的

6. **审批流：坏品退货审批**
   - 坏品数超过阈值 → 自动发起退货审批 → 主管确认 → 通知采购执行退货
